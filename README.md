# vtex-app-source-download

Skill do Claude Code para baixar o código-fonte de versões publicadas de apps VTEX IO
direto do Registry da VTEX, usando a sessão do VTEX CLI. Detalhes em [SKILL.md](SKILL.md).

## Instalação

```bash
git clone git@github.com:gsbenevides2/vtex-app-source-download.git ~/.claude/skills/vtex-app-source-download
```

Requer `python3` e o VTEX CLI logado na conta (`vtex login <account>`).
